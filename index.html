Ejercicios de sonidos

Conectar con Claude

El entrenador necesita una clave de API de Anthropic. Créala en console.anthropic.com. Se guarda solo en este navegador y se envía directamente a Anthropic. El uso se cobra en tu cuenta de Anthropic.

Las voces “Google”, “Natural” u “Online” suelen sonar mejor. Si no aparece ninguna, tu dispositivo no tiene voces en español instaladas.

Elige una escena

Usa Chrome o Edge para la voz. Tú hablas, tu compañero te responde en voz alta y el entrenador te señala las palabras que no se entendieron bien.
